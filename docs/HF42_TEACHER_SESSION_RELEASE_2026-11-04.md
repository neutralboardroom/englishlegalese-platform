# HF42 — real 50-minute teacher sessions and separate student projector slides
Date 2026-11-04; parent HF41 abc5b2fe0c6b84dc31ba2de2573a2ab13043d1b0. Fourth cumulative improvement in the HF39–HF43 five-version series.

**Problem** Owner's real classroom: four 50-minute lessons per day, around 25–35 learners, paired student speech, teacher with a handheld microphone, projector, occasional uncertain room speaker routing, varying proficiency. Teacher needs exact cue wording and timed flow, and should not inadvertently read teacher-only prompts on the student projector. Specialist Legal/Business lessons had no practical 50-minute teacher script.

**Function** Each of 24 professional Legal/Business lessons gains a complete eight-stage 50-minute schedule with explicit question and model reply drawn from original fictional dialogue, pronunciation practice, pair talk, role swap, up to two student presenters at front, feedback, and exit response. A separate native-dialog learner-only projector view displays eight large readable classroom prompts, user-controlled Next/Previous/Close, without teacher notes/answer key. Teacher must preview language and any translations; no automatically spoken Thai or always-on AI audio. On lost audio, text-only speaking and partner interaction still work.

**Truth/privacy** This is a self-contained instructional aid, not a scheduled class, authenticated teacher dashboard, student record, AI rating, attendance system, certification, payment or live tutor. No class data, mic access, network submission, private client facts, account changes, backend migrations or email. No homepage/photo/locked logo changes.

**Research decisions** Adapt Council of Europe CEFR mediation and oral interaction (https://www.coe.int/en/web/common-european-framework-reference-languages/mediation-in-the-classroom), British Council cooperative feedback (https://www.teachingenglish.org.uk/professional-development/teachers/managing-lesson/conducting-feedback-exercises-and-tasks), Cambridge teaching/learning framework (https://www.cambridgeenglish.org/educators-organisations/professional-development/teaching-framework/). Teacher-facing text can be verbose; projector shows only learners' questions. Defer genuine supervised CEFR assessment, AI conversation, recording and student reporting until authorized, provisioned and independently tested.

**Qualification** Static exact 50-min arithmetic + semantic no-write controls + 4-device browser tests and screenshots, two independent exact-final-head gates before merge, Render + both official host verification after merge. Complete prior backlog retained.
