## HF68 new actual source work (entire inherited HF1–HF67 site retained)
1. **Complete private workspace subtree no-cache:** `server.js` now uses `hf68IsPrivateWorkspace(pathname)` for both pre-routing response headers and Express static-serving headers. Its boundary-aware prefixes cover nested account, private-class, saved-work, teacher, student, employer, owner and progress URLs including encoded `index.html`. These responses have `Cache-Control: private, no-store, max-age=0`, `Pragma: no-cache`, `Expires: 0`, `Vary: Cookie, Authorization`, and `nosniff`; all `/api` routes remain no-store. Public course/price page caching is unchanged. This is HTTP response protection, not a claim that historical browser data has been removed.
2. **Real public mobile-app asset integrity:** The existing voluntary `Check my device and public app files` action now rejects HTTP redirects, failed/incorrect MIME, responses larger than 1 MiB by declared length and bounded failed requests; it verifies `manifest.id`, scope, start URL, standalone display and **exact icon paths**. For both 192px and 512px icons it checks the actual PNG binary signature, IHDR header and exact dimensions. A mislabelled/corrupt icon is reported as invalid, not falsely “install-ready.”
3. **Explicit consent and no-cookie boundaries remain:** Device checks still run only after the user clicks, fetch only the public manifest and two public same-origin icon paths using `GET`, `credentials:'omit'`, `cache:'no-store'`, and `redirect:'error'`. They never query private accounts, student class data, marketing, payments, or any outside service, and never automatically download or install a native app. Existing Android/Chrome PWA prompt and iPhone/iPad Safari Add-to-Home-Screen path remain optional. The PWA is web-based, not a native App Store binary.
4. **New executable negative security tests:** `scripts/verify-hf68-mobile-integrity.js` simulates valid, corrupt, missing and redirected icon/manifest responses without any user account, network or live provider; `tests/hf68-mobile-integrity-private-cache.spec.js` checks actual browser public-asset integrity and same-origin private nested HTTP no-store headers across desktop, tablet and mobile Chromium and tablet WebKit. Both tests added to the inherited mandatory `npm run check` and Release Gate, without dropping earlier validations.
5. **Strict no-drift and provider boundaries:** Approved homepage teacher photograph, logo/favicons, navigation, Legal English and Business English hubs, every curriculum and free tool, role dashboards, certificates/assessment policy, subscriptions/pricing, class confirmation, source-of-truth and teacher/student controls remain unchanged. No email, payment, enrollment, live Google Calendar or Meet, data migration or Teacher Roger sibling project mutation. User's former HCMC private learner remains inactive.
