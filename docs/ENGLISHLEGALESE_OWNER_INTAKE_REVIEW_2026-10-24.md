# EnglishLegalese — private enrollment and teacher review (October 24, 2026)
This is the operational follow-up procedure for v1.85.0. These are genuine website intake forms stored in the dedicated EnglishLegalese Neon database. **Do not advertise an automatic confirmation, automatic owner alert or payment.** Sending email, teacher acceptance and student enrollment confirmation require a separate intentional owner action.

1. **Each business day:** check the intake queue in the private Neon console or from an authorized private shell with `npm run owner:intake:review`. The default CLI outputs counts only and no names or addresses. Store DB connection secrets only in environment variables.
2. **Optional private review file:** `npm run owner:intake:review -- --export=/secure/path/intake-review-2026-10-24.csv --acknowledge-personal-data`. This creates a **new** owner-controlled file with 0600 permissions and refuses overwriting. Keep it outside public directories, GitHub, shared folders and logs. This export is a snapshot, not an API or automatic synchronisation. Never email the full file.
3. **Enrollment:** verify request reference, contact details and selected track. Confirm teacher/time availability before sending any private class joining information. Confirm class place and terms individually. Payment is **disabled**. Follow up once after 2 business days if the applicant has not replied, unless consent or suppression requires otherwise.
4. **Teacher application:** assess qualifications, subject expertise (Legal/Business/Investor), teaching demonstration, timezone, work authorisation and privacy awareness. Check suitability before contacting a student. Do not publish applicant information or claim employment/assignment without individual confirmation.
5. **Record next action privately:** use the CSV review_status, followup_owner, next_action, last_contact_utc and next_followup_utc columns. Record contact/suppression and avoid duplicate follow-up. Safeguard retention and access. No data is overwritten in the underlying database by a CSV edit.
6. **Not yet automated:** owner notifications, calendar invitation delivery, teacher selection, payment, automated status writeback. Do not call these complete until explicitly configured and independently tested.
7. **Protected scope:** no AI avatar tutors, no public applicant directory, no unverified teacher profiles, no legal or financial advice, no changes to the protected laptop homepage design or legacy curriculum.
