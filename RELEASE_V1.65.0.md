# EnglishLegalese v1.65.0 — three-case AI Draft Review Lab

This material improvement adds a separate, opt-in free lab for learners to practise reviewing fictional AI-generated legal-business writing. It covers a made-up mandatory deadline, an unsupported legal conclusion, and a prompt to upload sensitive client identifiers to an unapproved AI service. Learners select a recommended risk response and can write their own fictional safer alternative; the lab shows contextual reasoning and concrete self-check criteria without presenting an accredited score. A progress indicator only counts reviewed cases on the current page; reset clears everything.

The lab provides **no live AI inference** and does not send practice data to the server; existing SmartTeacher prompt-preparation remains a separate on-page tool, not evidence that `OPENAI_API_KEY` is installed. Navigation links from SmartTeacher and the existing footer, and the AI-output-review diagnostic category now opens this actual educational lab.

Original approved logo, home page structure, public 9-course catalog, 21 scenarios, eight-question debrief, three private writing exercises, backend, authorization and protections preserved.
