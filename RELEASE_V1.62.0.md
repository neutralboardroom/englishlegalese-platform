# EnglishLegalese v1.62.0 — practical learner experience and reliable navigation

**Candidate, not yet deployed.** This is a material, user-visible successor to verified v1.61.1.

Students, teachers and employers see shorter, less operational wording. The nine-course expansion button uses a correct collection operation. The SmartTeacher section now honestly describes its local guided prompt-builder functionality, allowing the user to prepare a substantive conversation or writing review prompt and copy it to a connected learning tool; it does not claim to run ChatGPT directly, produce simulated AI feedback, store a real lesson or grant accreditation. Empty input generates only a synthetic practice topic; user input is written as plain text rather than HTML, and local text isn't sent anywhere in this workflow.

The responsive primary navigation now handles Escape (restoring focus), link activation, outside pointer close and accessible aria-expanded state. Current section highlighting improves orientation. SEO title, metadata and social preview text reflect the actual public feature set.

Unchanged: approved permanent logo image, header sizing, 21 scenario IDs, 8-question diagnostic, core courses and planner, privacy, protected role routing, original backend and data model. The inherited next-version list is preserved. Requires two independent full exact-head release gates plus separate real production acceptance.
