# EnglishLegalese v1.75.0 — Fresh research, pedagogy and implementation decisions (2026-10-20)
- MDN Web Speech API SpeechSynthesis.speak()/cancel(): browser speech playback can be started and stopped using user gestures. https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/speak and https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/cancel . **ADAPT**: optional speech with stop, slowed replay and explicit transcript fallback; no server-side voices or paid API.
- MDN SpeechSynthesis browser voice controller: https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis . **ADAPT**: absence or failure of device voice must never block learning. **REJECT**: overclaim human recordings or automatic speaking assessment.
- Legal English programs/certifications and practice-oriented broader English-learning products: **DEFER_WITH_REASON**: do not describe self-check questions as accredited assessment/TOLES/CEFR; original fictional scenario content avoids copyright and qualification risks.
- Existing EnglishLegalese audits and workflows: v1.74 was fully live but the v1.73 legacy production workflow matched any commit message mentioning predecessor v1.73, causing an obsolete false alarm. **ADOPT** exact version-title prefix workflow guards and independent current live-browser acceptance.
- Pedagogy: focus on distinguishing reported versus verified facts, target versus deadline, may versus must, each with three explicit comprehension rationales and native choices. This supplies a genuinely different *listening* learning mode rather than another writing editor.
All sources are implementation research, not a representation of external certification or partnerships.
