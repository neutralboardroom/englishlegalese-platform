**Fail closed, not stop permanently:** If any gate fails or a provider blocks actions, keep existing live service intact, repair within the same source/version lineage, retry qualification, preserve evidence, and complete release when gates are satisfied. Record an explicit BLOCKED status; never quietly redefine a blocked version as "finished" or infer that the owner has revoked the standing authorization. Never merge failing code into auto-deploying `main`.
